# Conway's Game of Life

This is my version of Conway's Game of Life made in Python. I made this project to get more practice with Python and learn how the Game of Life works.

The program lets you either create a random board or load one from a text file. It then displays the simulation using Tkinter and updates the board based on Conway's rules.

## How to Run

Make sure you have Python installed, then run:

```bash
python main.py
```

When the program starts, you can choose to:

* Generate a random board
* Load a board from a text file

## Files

* `main.py` - Starts the program and handles user input.
* `map.py` - Contains the Game of Life logic.
* `display.py` - Draws the board using Tkinter.
* `tests.py` - Unit tests for the project.
